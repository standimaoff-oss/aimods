# aimods — AI Arsenal (Forge 1.20.1)

Мод `aiarsenal`: техника, авиация, ракеты, стрелковое оружие (АК-12, M4A1, РПГ-7В2, ORSIS T-5000, ПКП «Печенег») и т.д.

- `mods/aiarsenal/` — исходники мода (Forge 47.4.23, Java 17). Сборка: `cd mods/aiarsenal && ./gradlew build`
- `mods/aiarsenal/src/main/resources/` — ресурсы (GLB-модели, текстуры, звуки, json)
- `tools/` — скрипты Blender (`tools/blender/*.py` — все модели), генераторы звуков/данных, сборка и тесты
- `notes/` — планы и ТЗ, `reports/aiarsenal.md` — отчёт по всем изменениям

Minecraft 1.20.1, Forge 47.4.23, Java 17. Заменить старый JAR на клиенте и сервере,
не оставлять две версии. **Перед обновлением сделать копию своего мира.**

### Воспроизведение

Сборка: `bash tools/build.sh` (Java 17 на PATH или через JAVA_HOME).
Кэши Minecraft/Gradle остаются вне исходников.
`.github/workflows/stage1e-verify.yml` собирает JAR, запускает GameTests, миграцию,
установленный клиент, записывает X11/PulseAudio и сохраняет доказательства.
Workflow можно запустить вручную на текущей рабочей ветке; успешный CI создаёт
только draft, публикация выполняется отдельно после проверки результатов.
