# Перезарядка, шейдеры и комфорт — текущая проверка

Дата: 16.10.2026. Новый выпуск **не одобрен** до завершения повторных проверок.

## Изменения

1. **Серверная перезарядка:** возраст последнего ввода 5–100 тиков при удерживаемом R теперь
   приостанавливает прогресс вместо обнуления. Прогресс не растёт и боеприпасы не расходуются.
   Отпускание, выход из места, потеря боеприпасов/возможности загрузки или молчание более 100 тиков отменяют её.
   Допуск свежего управляющего ввода остаётся 4 тика; огонь и движение не получили расширенную аренду.
2. **Слепота/тошнота:** удалена выдача этих двух эффектов из дыма, обеих реализаций ядерного взрыва
   и радиационной болезни. Сохраняются визуальные вспышки, дым, потеря цели мобами, урон и прочие эффекты радиации.
   Глобального запрета ванильных эффектов нет.
3. **Шейдеры:** существующий fail-closed Iris/Oculus guard не допускает сырой объёмный GL/FBO-проход.
   Дополнительно частицы взрывов передаются штатному ParticleEngine со стандартным translucent render type;
   при включении шейдеров во время эффекта передаётся и владение ticking, без двойного обновления.
   Legacy-ядерное облако сохраняет геометрию через управляемый `RenderType.entityTranslucent`, без прямого
   additive GL-pass под шейдерами. Вспышка остаётся GUI-отрисовкой, не статусом blindness.
4. **Конфликт R:** Oculus 1.8.0 по умолчанию использует R для пересборки шейдеров. Это совпадает с
   перезарядкой мода; в прежних и новых логах видно уничтожение/создание pipeline после R.
   Добавлен контекстный приоритет: с оружием/в пусковой R перезаряжает оружие, а не шейдеры.
   Назначения клавиш не изменяются; без оружия и вне машины действие Oculus остаётся доступным.
5. **Диагностика:** журнал сохраняет возраст ввода/таймер загрузки/последнее состояние машины,
   цель под клиентским прицелом, счётчики shader-safe частиц и облаков и активные статусы игрока.
