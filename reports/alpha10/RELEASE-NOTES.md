- Guard активного Oculus/Iris shaderpack с fallback-эффектами; без пакета объёмный рендер сохранён.

## Границы результата

Для 160 предметов полная контекстная функция остаётся NOT_VERIFIED. Это не завершение всей приёмки самолётов, дронов, кораблей, ЗРК, управляемых боеприпасов и специальных инструментов.
Photon проверен на Linux llvmpipe с `SH_SKYLIGHT=false` из-за ограничения shared memory стенда; стандартный пресет и Windows/NVIDIA не сертифицированы.
Связь исправленного OpenGL-дефекта с конкретным присланным `nvoglv64.dll` crash пока не доказана; нужен hs_err и аппаратный повтор.
