## Что добавлено в alpha.5

1. Отдельная установка Forge через pinned minecraft-launcher-lib 7.1. Клиент запускается
   как **forgeclient**, сервер — установленным run.sh; оба используют один reobfuscated JAR.
   Это **не** ForgeGradle userdev и не запуск классов из исходников.
2. C96/ТТ получили разные оригинальные процедурные mono OGG, SoundEvent и субтитры.
   Это игровые SFX, не записи настоящего исторического оружия.
3. У старого звука ППШ оставлен запас уровня для очередей; исходники сохранены перед
   заменой. Ни громкость захвата, ни аудиофильтр не используются для обхода проверки.
4. Настоящий вывод X11 + OpenAL/PulseAudio записан в пять непрерывных MP4.
   Устранены прежние dup/drop и крупные аудиобуферы. В финальных логах ffmpeg нет
   dup/drop; частота **захвата** около 20 кадров/с — это не измерение FPS игры.
5. Измерение звука исправлено: исходные два канала, 48 кГц, без downmix/ресемплинга;
   максимум берётся по всем каналам. Прежний mono-downmix добавлял до 3 дБ и мог
   давать ложный перегруз. Порог остался **peak < 0.99**; добавлены regression-тесты.

## Границы и следующие этапы

- Runner использует **llvmpipe**, render distance 2, облегчённый software-проход VolPyro,
  heap клиента 2 ГиБ. Аппаратные GPU, высокий пресет и FPS на пользовательском ПК не проверены.
  В базовом ТЗ предусмотрен software renderer; аппаратный тест не выдан за пройденный.
- Объективная проверка аудио не заменяет оценку звучания человеком. Полные видео переданы
  заказчику для просмотра/прослушивания и визуальной приёмки по ТЗ.
- Геометрия не менялась относительно alpha.4 с живым Blender/MCP-review.
- Форма/звания СССР и Германии, редкое оружие, Панцерфауст/гранаты, последующие эпохи,
  оптимизация по танковому референсу и новые locomotion-анимации — **отдельные этапы**.
- В main не слито. Старые alpha.4 и бэкапы сохранены; промежуточная alpha.5
  `stage1e-38723155778` не опубликована. История исправлений: [STATUS](../../notes/stage1e/STATUS.md).
