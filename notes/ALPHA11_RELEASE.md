# Alpha.11 — экспериментальная сборка: перезарядка и shader-safe эффекты

**Это ограниченная тестовая сборка, не заявление об устранении всех вылетов или проверке всех режимов каждого предмета.** Перед установкой сохраните копию мира. Minecraft 1.20.1, Forge 47.4.23, Java 17. Замените прежний `aiarsenal` JAR; не оставляйте две версии одновременно.

## Изменения

- Устранён конфликт оружейной клавиши R с пересборкой Oculus: обработчик мода выполняется раньше. Без оружия и вне пусковой действие Oculus остаётся доступным; настройки клавиш не переписываются.
- Долгая перезарядка сохраняет прогресс при коротких паузах ввода до 5 секунд. Просроченный ввод не продвигает загрузку и не выдаёт боеприпасы. Отпускание/выход/долгая потеря ввода отменяют её.
- Мод больше не выдаёт статусы слепоты и тошноты из дыма, ядерных взрывов и радиационной болезни. Ванильные и чужие эффекты глобально не запрещены. Вспышка, дым и остальные последствия сохранены.
- При активном Oculus/Iris взрывы используют управляемые Minecraft частицы/RenderType вместо небезопасного собственного GL/FBO-прохода. Проверены переключения паков во время эффектов.
- По Первой мировой добавлен только [план](https://github.com/standimaoff-oss/aimods/blob/71dd4b6c9394f3c426421f3ab15d2b920f99b95d/notes/WWI_PREPARATION.md). Новых WWI-моделей, регистраций или механик нет.

Пороховые пушки заряжаются ПКМ зарядом, затем поджигаются огнивом; R используется оружием и соответствующей техникой.

## Открытые ограничения

- Windows/NVIDIA native crash из пользовательского лога **не подтверждён как устранённый**. Linux llvmpipe не заменяет этот аппаратный прогон; нужен полный `hs_err` для дальнейшего разбора.
- Нет сертификации всех shaderpacks, версий, GPU или OptiFine. Photon на стенде использовал указанное выше отключение skylight.
- 160 строк основного каталога остаются без отдельной функциональной отметки. Дополнительные контекстные сценарии не закрывают все режимы техники, полёта, обслуживания и GUI. Это не полная приёмка всех 448 предметов.
- Кадры Bismarck/MQ9 показывают HUD и небо, не подтверждая внешний вид/полноценную камеру этих объектов. Серверные расход боеприпасов/появление снарядов проверены отдельно. Bismarck прошёл повтор, но причина прежнего единичного отказа не установлена окончательно.
- Разрушения бомб проверялись отдельно от shader-сценариев визуальных пакетов. Близкие shader-кадры не проверяют форму целого ядерного облака на расстоянии.
