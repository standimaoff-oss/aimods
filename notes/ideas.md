# AI Arsenal — что ещё можно добавить

Блоки для построек (окопы, флаги, двери, обломки, структуры) уже распланированы в notes/plan_blocks.md. Ниже всё остальное.

## Механики
- **Модули техники**: двигатель, гусеница, ствол, боеукладка, экипаж. Раздельные повреждения с ремонтом ремкомплектом
  (сбитая гусеница = стоп, детонация БК = срыв башни).
- **Броня по углу**: приведённая толщина и рикошеты, разные снаряды (ОФ / БОПС / кумулятив / ПТУР-тандем), ДЗ «Реликт» и КАЗ «Арена».
- **Дым и тепловизор**: дымовые гранатомёты 902В, тепловизор/ПНВ в прицелах, ночные бои.
- **Буксировка**: Урал тянет Д-30 / М777 / прицеп, сцепка по ПКМ.
- **Транспорт и десант**: БМП / Урал / вертолёты высаживают пехоту, десантирование с Ту/Ил на парашютах.
- **Топливо и снабжение**: бочки ДТ из r12 заправляют технику, топливозаправщик, склад БК.
- **Связь и РЭБ**: глушилка дронов, подавление GPS для крылатых ракет, радиостанция для вызова арт-удара.
- **Погода**: ветер сносит снаряды и дым, дождь и туман ограничивают видимость.
- **Боты**: экипажи-NPC, наводчик ПВО, патрули на базах из части 4 блоков.
