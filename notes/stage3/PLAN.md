# Завершение отложенной части: движения и рендер

Исходная опубликованная версия: alpha.6 / source 7bc05a1 / evidence 4ef08f3.
Рабочий snapshot оказался старее публикации: прежде чем обновлять его, сохранены
/home/user/backups/stage3/workspace-before-update.tar.gz, SHA256SUMS и git stash.
Ветка не менялась, опубликованная alpha.6 и прежние резервные точки не удалялись.

Объём:
- Пять процедурных состояний удержания: стояние, медленная ходьба, ходьба, бег,
  приседание; смешивание по игровым тикам, интерполяция кадров, отдельное состояние игрока.
- Alt (переназначаемый): медленная ходьба с оружием. ADS гасит движения до точного нуля,
  перезарядка имеет приоритет; поддерживающая рука следует преобразованному цевью.
- Third-person использует реальное сетевое перемещение/флаги игрока, не ADS наблюдателя.
- Оптимизация точечного GLB-рендера: индекс примитивов по узлу вместо полного просмотра
  всех примитивов для каждой детали формы. Геометрия/материалы/порядок проходов неизменны.
- 5 новых GameTests + полный предыдущий набор; реальные first/third/remote состояния,
  F2/видео, ADS/перезарядка, проверка индекс=старый проход, A/B/B/A в одинаковой сцене.

Не подменять проверку аппаратного GPU программным llvmpipe. Не заявлять переработку
танков по отсутствующему референсу: точное изображение заказчика в предыдущем поиске
не найдено. Этот проход оптимизирует алгоритм рендера, а не выдумывает новый танковый дизайн.

Движения завершены и включены в публичный stage4-38770590840 (15.10.2026):

референсу не было. Это ограничения результата, а не скрыто выполненные пункты.
