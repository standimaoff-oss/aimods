## Реализация (контрольная software-client QA пройдена; ограничения ниже)
- Отдельные MOSIN_PU (ПУ 3.5×), K98K_ZF39 (ZF39 4×), C96, TT33; новые enum IDs добавлены в конец.
- Раздельные исторические сетки, фиксированное увеличение, загрузка снайперских винтовок одиночными
  патронами (прицел мешает обойме); C96 10-местный несъёмный магазин/обойма только пустому,
  ТТ-33 съёмный магазин 8 + возможный патрон в патроннике.
- Новые модели строятся через **живой Blender GUI 4.2.5 + pinned Blender MCP**, а не bpy headless.
  Скрипты сами по себе НЕ считаются выданной моделью. Обязательны фактические .blend/.glb,
  get_viewport_screenshot и затем настоящие F2 Minecraft; конвейер запускается в GitHub Actions.
- Первоначально используются существующие звуковые события ППШ для пистолетных выстрелов;
  это не специально записанные звуки C96/TT.
- Урановые block/item registrations удалены, удалены worldgen, добыча, плавка, теги. Это не скрытие.
  Старые блоки remap → stone/deepslate; raw → iron nugget, ingot → iron ingot. Миграция требует
  отдельного испытания на старом мире. Ядерный игровой рецепт больше не зависит от урана:
  его абстрактный rds_core использует vanilla iron_block, все 4 прежних ядерных рецепта сохранены.

## Ракеты: не удалять наугад
У всех пока найденных зарегистрированных семейств есть носители:
- BM21 9M22U/9M28F/9M22S/9M218/9M43; Grad/Smerch/TOS; BM13/Sturmtiger.
- SAM 48N6 → S400; ракеты вертолётов/самолётов/кораблей → их системы вооружения.
- Kh101/Kh55 → Tu Bombers; Kalibr/Tomahawk → cruise launcher/носители; Yars → TEL.
- Generic missile_tactical/operational/cruise/icbm → LaunchPadBlockEntity.interact/canAccept,
  LaunchComputer. Это боеприпасы **действующих стационарных пусковых установок**, а не бесхозные вещи.
- PG7V, Igla/Stinger/Javelin → ручные пусковые устройства; по формулировке «и т.д.» сохранены.
Нельзя удалять эти семейства просто по слову rocket/missile. Пока ни одна ракета не удалена:
нужен доказанный список НЕиспользуемых, либо отдельное решение удалить сами стационарные комплексы.
Добавлен серверный регрессионный тест сохранности ядерок/дронов/боеприпасов техники.
