# Франция и Российская империя — оружие 1812 года

Новые предметы находятся в отдельных вкладках **1812 · Оружие**, **1812 · Артиллерия** и **1812 · Боеприпасы**. Ранее добавленные мундиры обеих армий сохранены.

| Франция | Российская империя |
|---|---|
| Мушкет 1777 / An IX (`musket_1777`) | Пехотное ружьё обр. 1808 (`musket_1808`) |
| Пистолет An XIII (`pistol_an13`) | Кавалерийский пистолет обр. 1809 (`pistol_1809`) |
| Тесак-брикет (`sabre_briquet`) | Кавалерийская сабля (`sabre_1809`) |
| 6-фунтовая пушка An XI (`cannon_fr6`) | 12-фунтовая пушка обр. 1805 (`cannon_ri12`) |

## Ручное оружие
- **ЛКМ:** выстрел; **ПКМ:** прицеливание; **R:** перезарядка.
- Мушкеты используют `paper_cartridge`, пистолеты — `pistol_cartridge`.
- Один патрон — один выстрел; сменного магазина и дополнительного патрона в патроннике нет.
- Заряжание с бумагой и шомполом занимает 8 секунд для мушкета и 6 секунд для пистолета. Это ускоренный игровой темп, не реконструкция времени исторического заряжания.
- Сабли используют обычное управление ближним боем Minecraft.

## Пушки
1. Поставить пушку ПКМ по свободной поверхности.
2. ПКМ пустой рукой — направить по своему взгляду; **Shift + ПКМ** пустой рукой — изменить возвышение ствола.
3. ПКМ с соответствующим зарядом: `charge_fr6` либо `charge_ri12`. Заряды разных калибров не взаимозаменяемы.
4. Подождать 8 секунд. Огниво в основной руке + ПКМ по пушке — выстрел.

Заряд уже включает ядро. Оно летит по баллистической траектории и наносит прямой урон: **это не взрывной снаряд**. После выстрела откатывается лафет, а не отдельный ствол на современном противооткатном устройстве.

## Дым и совместимость
- Собственный объёмный дым выстрела, порохового залпа, выхлопа, попадания ядра и обычного взрыва использует отдельное поле плотности и палитру на основе рендера VolPyro.
- Дым создают игровые выстрелы и работающие двигатели; он не ограничен демонстрационными командами.
- Ядерные функции и четыре исходных шейдера донора сохранены. Ракеты носителей, ПВО, дроны и прежнее оружие не удалены.
- Цель сборки: Minecraft **1.20.1**, Forge **47.4.23**, Java **17**. Для обновления существующего мира сначала сделать резервную копию и заменить прежний JAR, не устанавливать две версии мода одновременно.

## Движение с огнестрельным оружием
- **Alt + направление:** медленный шаг; клавишу можно переназначить в настройках управления.
- Обычная ходьба, **Ctrl + направление** для бега и **Shift** для приседания используют стандартные привязки Minecraft.
- При полном прицеливании движение оружия подавляется, чтобы не сбивать линию прицела;
  при перезарядке приоритет у её анимации. Состояния других игроков приходят через
  настоящее сетевое перемещение, а не повторяют движение камеры наблюдателя.
