# Этап 1д — установленный клиент, собственные pistol SFX, непрерывное видео

Запрос: «доделай» после alpha.4. Исходная точка db4e485, опубликованный alpha.4 сохранён.
Без удаления старых ресурсов/миров. Геометрия/GLB не меняются; используются модели,
полученные и просмотренные в этапе 1г через живой Blender/MCP.

## Реализовано (итоговый результат ниже)
- Отдельная установка Minecraft/Forge 1.20.1-47.4.23 через pinned minecraft-launcher-lib 7.1.
  Клиент запускается как forgeclient, сервер через установленный run.sh; один и тот же
  reobfuscated JAR копируется в оба mods/. Никаких userdev source sets в клиентском classpath.
  SHA256, точная команда и происхождение сохраняются в отчёте. Только закрытый loopback QA.
- Полный прежний игровой сценарий выполняется в этой установке, а не сокращённый launch-only тест.
- C96 и ТТ-33 получили разные оригинальные процедурные mono OGG и отдельные SoundEvent/субтитры,
  вместо sound ID ППШ. Это игровой sound design, не записи настоящего оружия.
- Для ППШ и четырёх WWII-оружий записывается непрерывное видео настоящего окна Minecraft
  с реальным выводом OpenAL → PulseAudio monitor. Захватывает выстрел/затвор/перезарядку.
  Аудиодорожка декодируется и проверяется на тишину/клиппинг. Кадры из видео отдельно
  обозначены video-review, не выдаются за F2. MP4 хранятся в CI artifact/release, не в Git.
- Сохранены все проверки GameTest/миграции/эффектов/прицелов/каталога. Только полностью
  успешный прогон создаёт draft alpha.5; публикация после просмотра, не вместо проверки.

## Границы
GitHub runner остаётся llvmpipe. Аппаратный GPU/FPS не будет объявлен проверенным.
Субъективное качество звуков не подтверждается одной проверкой RMS: видео отдаётся для
прослушивания. Новые эпохи, форма и отложенная оптимизация/locomotion не подмешиваются.

## Повторный прогон 38725195609: исправлена ошибка измерения
Build/GameTests/миграция PASS, клиент остановлен строгой аудиопроверкой на ППШ.
Захват исправлен: 293 кадра, около 20 кадров/с, без ffmpeg dup/drop и двухсекундных рывков.
Пик 1.384 при старой методике нельзя трактовать как пик исходного стерео: `-ac 1`
у ffmpeg суммирует L/R с коэффициентами ~0.707, а не усредняет. Локальный контрольный
стереосигнал 0.8/0.8 дал 1.13137 после такого downmix. Теперь измеряется исходный
декодированный PCM всех каналов, без смены частоты, downmix и аудиофильтров;
порог <0.99 прежний. Метрики сохраняются и при отказе, добавлены 3 regression-теста.
Для очередей ППШ дополнительно оставлен запас: исходный сэмпл нормализован до .32,
предыдущий сохранён в /home/user/backups/stage1e/smg_ppsh-before-burst-headroom.ogg.
Все 5 локальных audio-тестов PASS. Следующий полный прогон обязателен.
